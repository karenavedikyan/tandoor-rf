# Фотографии моделей бота: границы изменения

## Исходное поведение
- PR 178 выпущен; MAX проверен: один выбор «Дипломата» отправляет все 32 фото.
- Категории, модели, поиск, покупательские фильтры и возврат в список работают.
- Исходные записи, GUID и фотографии каталога остаются отдельными от бот-представления.

## Новое правило
- Входные двери: один выбор модели отправляет все уникальные фото, включая внутренние панели.
- Уникальность отправляемых фото определяется по проверенному SHA-256 готового бот-превью, а не только по пути файла: копии внешней/внутренней стороны для разных размеров и открываний не повторяются.
- «Амулет»: четыре размерных/сторонних исполнения с одинаковой парой изображений дают два фото. Разные по содержимому внутренние панели сохраняются; ограничение «всегда не больше двух» не применяется.
- Сравнение выполняется только внутри выбранной модели. Если хеш отсутствует, фото сохраняется по исходному пути, без догадок по имени или цвету.
- Межкомнатные двери и фурнитура: один выбор отправляет одно фото, без автоматической серии.
- Для одного фото сохраняется соответствие выбранному цвету и другим фильтрам.
- Возврат «К моделям» сохраняет фильтры, поиск и страницу.
- Старые сохранённые ответы не переписываются; доставка ранее сформированных очередей не обрывается.

## Проверки
- Оба канала: MAX и Telegram; модульные тесты категорий, галерей, выбора цвета и возврата.
- Регрессия: сохраняются модельные списки, фильтры, отличающиеся панели и доставка с продолжением очереди; одинаковое содержимое по разным путям не увеличивает новую очередь.
- Проверить типы, сборку и отсутствие изменений исходных данных.
- Живая проверка новой версии выполняется только после отдельно разрешённого выпуска.
