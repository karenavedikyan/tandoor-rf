# Общий реестр администратора

## Границы
- Рабочий Тантрекер, не прототип каталога. Администратор уже имеет серверный доступ ко всем неудалённым трекам; не расширять права других ролей.
- Административный общий вид по умолчанию, отдельно личный реестр. Общий вид включает архивы и скрытые лично передачи; удалённые записи не восстанавливаются.
- Фильтры: источник создания (все/сотрудники/внешние), автор, период. Счётчики создания и ежедневная динамика за 30 московских календарных дней; продолжение не считается созданием.
- Персональная подписка администратора: выключено/все/сотрудники/внешние. По умолчанию выключено, без задней рассылки. Обычные персональные уведомления не меняются.
- Одно событие при создании во всех трёх канонических путях: ЛК/сотрудник-бот, внешний веб, внешний бот. Транзакционно; повтор подтверждения не дублирует уведомление.
- Серверные проверки admin, active, preview/CSRF; повторная проверка роли и подписки непосредственно перед доставкой в MAX/Telegram.
- Никаких реальных сообщений, запуска рабочих воркеров, импортов или production deploy без отдельного согласования.

## Основные проверки
- Bootstrap администратора с/без party содержит общий реестр, сводку и свою подписку. Чужие роли, preview целевого сотрудника и внешние capability не получают административные данные/настройки.
- PATCH настроек: сохранение, выключение/смена режима, собственность, валидация и CSRF. Не позволяет менять чужую подписку.
- События создания сотрудник→сотрудник, сотрудник→внешний, внешний→сотрудник, внешний→внешний. Режимы/дедуп/rollback/старые треки/последующие handoff.
- Delivery-time: отписка, смена роли/блокировка, удаление трека, архив/завершение без ложного запрета уведомления о создании.
- Аналитика: from_external отражает автора при создании, точные created_at, московская граница суток, уникальные авторы, архив и soft delete учитываются явно.
- Реальная UI-проверка администратора и обычной роли: общий/личный вид, источник/автор/период, открытие карточки, настройки и перезагрузка. 375px/desktop, светлая/тёмная темы, клавиатура, ошибки консоли.
- Регрессия существующих scope/bootstrap, native create MAX/Telegram, личных уведомлений и общих тестов.

- Новая интеграционная матрица: 5 PASS (реальные транзакции, HTTP/CSRF/роли, все три пути создания, idempotency/replay, rollback, отписка и повторное включение, роль/блокировка/soft delete, MSK-граница суток).
- Существующие scope/admin-without-party/native external MAX+Telegram: 36 PASS. Registry cleanup + staff fanout: 12 PASS.
- Реальный браузер на изолированной БД: общий вид показывает 4 трека, сотрудники 3, внешние 1, личный 1; фильтр автора 2, период, пустой результат и полный сброс, 30 строк динамики, карточка и возврат, обновление.
- Все четыре режима подписки сохранены через UI, подтверждена перезагрузка; обычный сотрудник не видит ни панели, ни административных подписей.
- 375px и 1440px с переходом туда/обратно, светлая/тёмная темы, нет горизонтального переполнения и ошибок страницы. Мобильная плавающая кнопка скрыта во время редактирования подписки. Контраст текста по вычисленным цветам: #232c35/#fff, #ecf0e9/#222c25.
- Только синтетические пользователи/треки, отдельные disposable БД, воркеры и внешняя доставка не запускались. Рабочие данные, реальные подписки и production не менялись.
