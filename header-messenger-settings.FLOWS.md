# Каналы уведомлений в верхней панели

## Исходный экран
- В Comet открыт профиль в существующем режиме просмотра Рачика, открыт верхний колокольчик.
- MAX/Telegram в профиле скрыты, потому что preview-policy запрещает `/api/profile/*`, а не потому что статус чужой привязки был получен.
- Не менять текущий режим просмотра, настройки, привязки, треки и реальные сообщения.

## Требуемые сценарии
- Сотрудник открывает верхние уведомления и видит блок MAX и Telegram без поиска страницы профиля.
- Для неподключённого канала доступно подключение через существующий серверный API, затем явная ссылка на бота.
- Для подключённого канала отображается статус и включение/выключение уведомлений без отвязки аккаунта.
- Ошибка запроса не скрывает блок и не выдаётся за отключённую подписку; повторный запрос доступен.
- Возвращение из бота обновляет статус; ожидающая ссылка убирается после завершения привязки.
- Администратор и роли без ленты назначений имеют верхний колокольчик с настройками каналов, без запросов к недоступной ленте.
- Колокольчик Тан-трекера тоже содержит настройки каналов; текущая лента сохраняется.
- Режим «Войти как» показывает явное ограничение, не читает основную привязку и не делает POST.

## Регрессии и безопасность
- Лента, фильтры, прочтение, пагинация, обязательная оценка и закрытие диалога продолжают работать.
- Существующие привязки и профильный сценарий остаются прежними; никаких новых серверных прав и миграций.
- Desktop и 375 px: блок не выходит за экран, кнопки доступны с клавиатуры, консоль без новых ошибок.
- Локальные синтетические тесты, никаких реальных сообщений/привязок.
- Публикация новой функции требует отдельного разрешения владельца; предыдущий выпуск касался только получателей.

## Проверка реализации
- Новый общий блок встроен в ленту назначений и отдельный колокольчик Тан-трекера.
- Роли без ленты назначений получают колокольчик только с собственными каналами.
- Есть подключение, явная ссылка открытия бота, состояние ожидания, обновление ссылки, независимые переключатели, ошибки и повторная загрузка.
- Реальный локальный API: синтетический сотрудник подключил оба канала через UI и тестовые webhook; выключение MAX сохранилось в БД, Telegram остался включён.
- В сквозном тесте браузеру запрещена любая внешняя сеть; внешних запросов не было.
- Модульные тесты: 1443 passed, 0 failed.
- Серверные интеграции привязок, настроек и preview: 28 passed, 0 failed.
- Финальный браузерный набор: 19 passed, 0 failed (13 новых UI, 1 реальный локальный E2E, 5 существующих регрессий).
- Desktop 1440×960, mobile 375×812, короткое окно 1440×600, светлая и тёмная темы просмотрены вручную через локальный Playwright.
- Горизонтального переполнения нет. Минимальный замеренный контраст новых вторичных подписей: 5.80:1 в светлой теме, 7.60:1 в тёмной.

- Устранены гонка ожидания preview-start в старом браузерном тесте и жёстко заданный путь артефактов другого окружения.
- Браузерные проверки используют полный Chromium. Вспомогательный headless shell давал нестабильное зависание скриншота; полный Chromium прошёл финальный набор.
