# Держатель в списке «Статус трека»

## Объём

База: production PR139 `5899e1a90dcc029989f359caef2e3627edd5c736`.

- MAX и Telegram: в списке «Статус трека» вместо названия предмета показывается `№ трека · Имя текущего держателя`.
- Для `completed` добавляется «Завершён», для `obsolete` отдельно «Неактуален»; в пояснении указано, что у закрытого трека это последний держатель.
- Имя берётся через канонический resolver подробной карточки, только для уже разрешённых строк текущей страницы. Один запрос на уникального держателя, максимум пять на страницу, без вложенных подключений к пулу.
- Pending-получатель не подменяет держателя. До канонического OTP текущий держатель не меняется.
- Пустые или недопустимые имена заменяются «Имя не указано», значения только из телефона/email не показываются. Контрольные символы убираются, длинное имя ограничивается.
- Callback, карточки, поиск по номеру, сортировка и пагинация прежние. «Мои передачи» и «Архив», серверные права, статусы и данные не меняются.

Изменения локальные, без PR, merge и deploy. Нет миграций и изменения env/webhook/DNS/ролей; production не затрагивается.
