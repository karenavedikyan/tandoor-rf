# Контекстные кнопки MAX и Telegram (прототип, без публикации)

- **База:** `2210c6496db5d7c71163092610c2dcdccee61516`; ветка `cursor/tandoor-contextual-bot-buttons-without-release-cce4`.
- **Граница:** только разметка кнопок и безопасное переключение Telegram reply/inline; доменная логика, права, OTP, физическое подтверждение, webhook/env/БД без изменений.

## Домашний экран

- Кнопки: «Создать передачу», «Мои передачи», «Меню»; при активном черновике — «Продолжить оформление».
- `/start` и `menu_home` (sentinel) открывают домашний экран, не создают передачу.
- Текст «Меню» / callback `menu` с sentinel draft → компактная панель второстепенных действий.

## Компактное «Меню»

- «Получить код приёма», «Настройки», «К основным действиям», при черновике — «Продолжить оформление».
- Старые slash-команды и callback (`menu_receive`, `menu_settings`, `menu_create`, …) сохранены.

## Мастер

- Только кнопки шага + «◀ Назад» (кроме первого шага «Предмет») + «Отмена» + «Меню» (draft-bound → компактное меню, черновик не сбрасывается).
- Telegram: при входе/возобновлении мастера и в компактном «Меню» reply-клавиатура снимается отдельным служебным сообщением, затем идёт primary с inline; после компактного inline при необходимости восстанавливается домашняя reply-клавиатура (без смешения inline и reply/remove в одном `sendMessage`).
- Фото: до вложений — «Без вложений» (`photo_skip`); после загрузки — одно «Далее» (`photo_next`).
- Сводка: «Создать передачу», «Изменить», «Меню»; отмена через «Изменить» → «Отмена» или компактное меню.
- Редактирование: поля, «К сводке», «Отмена», «Меню» (без второго «Назад»).

## Мои передачи (держатель)

- Список: одна кнопка на передачу (`he:pick`), пагинация, «Меню».
- После выбора: «Ввести код», «Обновить приглашение»/«Приглашение», «К списку», «Меню».
- Список не выдаёт OTP; права holder/scope/handoff_version без изменений.

## Ввод кода / настройки / контакт

- Ввод кода: инструкция + «Отменить ввод»; после успеха — домашний экран с кратким текстом.
- Настройки и «Получить код»: кнопки раздела + «Меню».
- Верификация своего номера: «Отправить мой номер» + «Меню».

## MAX footer

- `withMaxMainMenuButton` добавляет «Главное меню» только если во inline нет contextual «Меню»; не дублирует навигацию.

## Ограничения

- Устаревшие сообщения: без новой подсистемы миграции клавиатур; stale callback fail-closed на сервере (как раньше).
- OTP и пересылаемое приглашение — отдельные сообщения без кнопок.
- Telegram delivery (`reply_extra`): optional `clearReplyKeyboard` → `primary` → optional `restoreReplyKeyboard` → copy-only / invitation / media; retry/dedup через существующие шаги `delivery.*`.
