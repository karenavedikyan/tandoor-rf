# Каталог по прототипу: границы и приёмка

## Исходный экран и эталон
- До изменений открыт production `/internal-catalog` через Comet: поиск, раздел, бренд, карточки, фотографии, пагинация; административный пилот.
- Эталон: `Tandor-unified-prototype/site/catalog-v1.js` и `catalog-v1.css`, просмотрен локально; снимок `catalog-prototype-before.png` вне репозитория.
- Сохраняем бренд, оболочку ЛК, вход, текущие серверные права, импорт, quality flags и прямые ссылки.

## Каталог
- Открыть раздел: реальные данные, источник и время загрузки; без подмены отсутствующих значений нулями.
- Дерево групп 1С: родитель включает потомков; chapter остаётся отдельным фильтром. Битые/циклические группы не скрывают товары.
- Поиск, бренд, свойства, тип цены, диапазон, наличие, новинки/хиты/акции, сортировка; сброс; пустой результат; ошибка и повтор.
- Виды «Как на сайте», «Витрина», «Таблица», разворот рабочей области; состояние в URL; назад/вперёд; пагинация.
- Фасеты только из явно переданных характеристик, не из догадок по названию.

## Карточка и фотографии
- Открыть карточку и прямую ссылку; все фотографии, увеличение и переключение; Escape и возврат фокуса.
- Цены с исходными названиями типов, остатки с названиями складов, дата загрузки; неизвестная единица не заменяется на «шт».
- Дубли с разными числами не суммируются и не выбираются произвольно; raw и красные замечания доступны.
- «Ответ клиенту» готовит текст для ручного копирования, ничего не отправляет.
- Подборка с количествами не переносится: единицы измерения и заказ не подтверждены.
- «Как видит клиент» скрывает все цены и точные остатки в UI/подготовленном тексте. Это не выдача доступа клиенту и не impersonation.

## Регрессии и исключения
- Существующие тесты доступа: аноним 401, остальные роли и admin-preview 403; HTML, API и фото одинаково защищены.
- Bootstrap остаётся ручным и с прежними проверками. Production импорт/деплой/миграции/расписания не запускать.
- Нет предполагаемых аналогов, совместимости, группирования только по имени, персональных цен или резервов.
- Проверка desktop и 375px, light/dark, пустые/длинные поля, ошибочные фото, гонки ответов, возврат URL, отсутствие console errors.
- Отдельные проверки: несовпадающие дубли цен/остатков; неизвестный тип цены; неизвестная/циклическая группа.

## Размеры одной модели
- Одинаковая исходная связь «СсылкаНаГлавную», исполнение, непротиворечивые заполненные свойства и известная цена выбранного типа: одна карточка, размеры по возрастанию. Служебное «Название для сайта» не является исполнением.
- Пропуск свойства не заполняется данными другого размера. При нескольких разных заполненных значениях размер с неизвестным значением остаётся отдельно и не связывает разные исполнения.
- На 375px «Таблица» показывает компактные строки: название не зажато ценой, размеры переносятся по доступной ширине, цена и наличие видны полностью. GUID скрыт только в мобильном списке, в подробной карточке сохранён.
- Размеры переключаются в «Витрине», «Как на сайте», «Таблице» и подробной карточке. Фото, GUID, свойства, качество, остатки и ответ клиенту принадлежат выбранному товару.
- Поиск/фасеты/наличие выбирают подходящий размер; остальные размеры видны с пометкой несоответствия фильтрам. Пагинация после группировки; количество карточек и товаров различается явно.
- Разные цены/цвет/покрытие/исполнение, неизвестные цены/связь/размер и неоднозначные дубли размеров не объединяются. Исходные записи не изменяются.
- Прямая ссылка на размер открывает этот GUID; переключение заменяет параметр product, закрытие/назад не зацикливает карточку.
