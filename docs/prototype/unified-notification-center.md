# Единый центр уведомлений ЛК (прототип)

**Решение зафиксировано:** 29.10.2026 — один постоянный центр уведомлений в личном кабинете; Telegram и MAX — каналы **доставки** того же центра, а не отдельные боты по модулям.

## Поведение продукта (демо)

| Аспект | Прототип |
|--------|----------|
| История | Все события (Tan-трекер, назначения, системные) в одной ленте `#af-inbox`, колокольчик `#af-bell` в шапке |
| Доставка | Настройки в профиле (`#af-profile-btn` → «Уведомления и доставка»): Telegram и MAX, общие предпочтения по типам |
| При отключении каналов | События **остаются** в ЛК; статус строки «Только в ЛК · мессенджеры не подключены» |
| При ошибке доставки | Событие **не удаляется**; демо-ошибка и «Повторить отправку» только симулируют push |
| Персональность | Привязка каналов и прочитанность — на демо-сотрудника (`localStorage`, ключ `tandoor-lk-notifications-demo-v1`) |
| Права | Настройки уведомлений **не** расширяют доступ к разделам; сохраняются правила ролей (ассистент без оценок, РОП без очереди решений и т.д.) |

## Границы приватности и ролей

- **Менеджер:** личные назначения, обязательные оценки, Tan-трекер в своей области видимости.
- **РОА / координатор:** очередь согласований, оценки, без подмены прав менеджера.
- **Директор:** просмотр активности и оценок, без оценки за менеджера.
- **Ассистент:** доступ к клиентам и уведомлениям о доступе; **нет** уведомлений об оценках и звёздах.
- **РОП:** информационные сообщения по команде, без кнопок решений и оценок.

## Отличие «история ЛК» и «статус доставки»

- **История ЛК** — содержимое центра уведомлений, фильтры, переходы в модуль (назначение, трек, клиенты).
- **Статус доставки** — вторичная строка под событием и блок в профиле; сбой или отключение мессенджера не отзывает событие из ЛК.

## Ограничения прототипа

- Синтетические фикстуры, без API, секретов, реальных учётных записей и привязки к ботам.
- «Подключить Telegram/MAX» — локальная симуляция, без QR, кодов и внешних ссылок.
- Сброс демо в «Назначениях» очищает `localStorage` центра уведомлений для воспроизводимости QA.

## Точки входа в коде

- UI и логика: `site/assistant-feedback.js`, стили `site/assistant-feedback.css`
- Интеграция Tan-трекера: `window.TanTrackerNotifications` в `site/tan-tracker-scope.js`
- Сброс демо: `AssistantFeedback.resetDemo()` из `site/assistant-workspace.js`
