# Единый центр уведомлений ЛК (прототип)

**Решение зафиксировано:** 29.10.2026 — один постоянный центр уведомлений в личном кабинете; Telegram и MAX — каналы **доставки** того же центра, а не отдельные bots по модулям.

## Поведение продукта (демо)

| Аспект | Прототип (preview) | Будущий рабочий ЛК |
|--------|-------------------|-------------------|
| История | Лента `#af-inbox`, колокольчик `#af-bell` | Серверная история уведомлений пользователя |
| Доставка | Telegram/MAX в профиле `#af-profile-btn` | Те же каналы, серверные привязки |
| Сохранение настроек | **Изолированный preview-backend** (`prototype/notification-demo-server.mjs`, порт **34113**), не browser storage | Персистентность на сервере ЛК |
| Идентификация | `X-Visitor-Id` (прокси на hosted preview; localhost QA — явный test visitor) | Сессия/учётная запись сотрудника |

## Preview backend (не production)

- Только синтетические `read`, `delivery`, `deliveryStatus` по **демо-сотруднику** (`m1`, `a1`, …) внутри одного посетителя preview.
- Файл данных: `prototype/.data/notification-demo-state.json` (gitignored).
- API: `GET|PUT|DELETE /v1/demo-notification-state`.
- Клиент: `site/notification-demo-store.js` + `window.__NOTIFICATION_DEMO_API__` в `site/index.html` (placeholder `__PORT_34113__` для rewrite при deploy).
- На hosted preview без rewrite API — честный режим «только память вкладки», без притворства успешного save.

## Границы приватности и ролей

- **Менеджер:** личные назначения, обязательные оценки, Tan-трекер в своей области видимости.
- **РОА / координатор:** очередь согласований, оценки, без подмены прав менеджера.
- **Директор:** просмотр активности и оценок, без оценки за менеджера.
- **Ассистент:** доступ к клиентам и уведомлениям о доступе; **нет** уведомлений об оценках и звёздах.
- **РОП:** информационные сообщения по команде, без кнопок решений и оценок.
- **Администратор (демо-роль):** служебные уведомления; настройки уведомлений **не меняют** права доступа к разделам.

## Отличие «история ЛК» и «статус доставки»

- **История ЛK** — содержимое центра, фильтры, переходы в модуль.
- **Статус доставки** — вторичная строка и блок профиля; сбой канала не удаляет событие из ЛK.

## Ограничения прототипа

- Без реальных ботов, SMS, учётных записей и production API.
- Сброс демо в «Назначениях» → `DELETE` состояния посетителя на preview-backend.
