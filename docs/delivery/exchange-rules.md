## 1. Подтверждено кодом / README (клиенты)

| Правило | Поведение | Источник |
|---------|-----------|----------|
| Модель файла | **Полный snapshot** массива записей; apply upsert по `guid_client` | `apply.ts`, README |
| Удаление отсутствующих записей | **Не выполняется** автоматически | README § восстановление |
| Уменьшение числа записей | `--apply` **отклоняется** (`RECORD_COUNT_DECREASED`), БД не меняется | `apply.ts` |
| Повторная загрузка того же файла | Upsert; unchanged/changed/new counts | `apply.ts` |
| Неизвестные поля объекта | Warning `EXTRA_FIELDS`; **не сохраняются** | `validate.ts` |
| Повреждённый JSON / UTF-8 | Отклонение до БД (`INVALID_JSON`, `INVALID_UTF8`) | `validate.ts` |
| Ошибки в записи | Запись пропускается; при любом issue count > 0 файл **не принимается** | `validate.ts` |
| Dry-run | Без PostgreSQL и без журнала | CLI |
| Apply | Требует `--expected-sha256`; файл перечитывается | CLI |
| Параллельный apply | Advisory lock; `IMPORT_LOCKED` | `apply.ts` |
| Прерванный apply | `running` в журнале → `STALE_RUNNING_IMPORT` | README |

## 2. Отличия: отсутствует / пусто / ноль (клиенты, **код**)

| Ситуация | Поле | Результат |
|----------|------|-----------|
| Ключ отсутствует | любой из 8 | **ошибка** `MISSING_FIELD` |
| Пустая строка после trim | `name_client`, `name_manager` | **ошибка** `EMPTY_NAME` |
| `guid_holding=""` и `name_holding=""` | holding | **допустимо** → NULL |
| Только id или только name holding | holding | **ошибка** `HOLDING_CONTRACT` |
| `address=""` | address | **warning**, запись ok |
| `telephone=[]` или все `""` | telephone | **warning**, запись ok |
| Число `0` в телефоне | telephone | **ошибка** типа (не string) |
| Доп. ключ `Discount: 0` | extra | warning; **не** сохраняется (синтетика) |

**Открыто (1С):** семантика «ноль» в будущих числовых полях (`DiscountAmount` и др.) — **не определена**.
