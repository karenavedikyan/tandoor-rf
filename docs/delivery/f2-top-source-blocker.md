## 2. Запрос специалисту 1С (один пакет для F2 + задел F3/F4)

Передать в 1С **одним** запросом (без PII в ответе в репозиторий):

1. **Актуальный structural slice** последнего `/LC/clients/all_clients.json`: метаданные (**дата формирования UTC**, **SHA-256**, число записей) + **обезличенные** 2–3 записи с блоками холдинга/категории/юрлиц/договоров, если они есть (значения → `"…"`, GUID → синтетические UUID, **сохранить ключи и вложенность**).

2. **ТОП / категория холдинга (F2):**
   - Точный **JSON-путь** (например `holding.top_category` или иной).
   - **Уровень:** холдинг, клиент (`guid_client`) или ТТ (`guid_store`)?
   - **Тип** поля: string / number / boolean / enum / массив флагов.
   - **Допустимые значения** и семантика **150 / 350 / 500**: одна категория на запись, несколько одновременно, иерархия «500 ⊃ 350 ⊃ 150» или иное правило.
   - Поведение при **отсутствии ключа**, `null`, пустой строке: omitted vs explicit clear (не выводить из названия холдинга, оборота или оргструктуры).

3. **Юрлица (F3, только структура):** имена ключей массива/объекта, cardinality (0..N), GUID юрлица, связь с `guid_client` / `holding` / `guid_store` — **без** реквизитов в PR.

4. **Договоры (F4, только структура):** ключи, GUID договора, связь с юрлицом/клиентом, cardinality — **без** номеров/сумм в PR.

Связанные открытые пункты: **Q8**, **Q10d** в [onec-specialist-questions.md](./onec-specialist-questions.md).
