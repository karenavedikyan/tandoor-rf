# Delivery — tandoor-rf

Документация поэтапного запуска ЛК. Актуализируется отдельными **документационными PR**; код приложения меняется только в соответствующих релизных PR.

## Правила работы

1. **Один PR за раз** — исследование/код/документация в одном PR; проверка в Chromium/Computer — отдельным шагом приёмки.
2. **Без самовольного расширения scope** — приоритеты, упрощения и перенос требований только после согласования владельцем и обновления эталона, плана и промптов.
3. **Без production-действий из Cursor** — merge, deploy, миграции на prod, импорт, создание пользователей и изменение доступов выполняет владелец/оператор по согласованному runbook.
4. **Без секретов и PII в Git** — пароли, токены, реальные выгрузки 1С, телефоны и адреса клиентов не коммитятся в документы, тесты и скриншоты публичного репозитория.
5. **Подтверждение фактов** — утверждения о текущей реализации сверяются с **свежим `origin/main`** (SHA фиксируется в PR и матрице приёмки).

## Приёмка релиза (100%)

Релиз считается выполненным, когда реализован **весь согласованный объём** этапа по функциям, структуре и фирменному стилю. Допустима адаптация под реальные данные и экраны без потери функций и стиля; **не** допустимы заглушки и неподключённые обязательные функции, выдаваемые за готовые.

Готовность одного PR ≠ готовность релиза.
