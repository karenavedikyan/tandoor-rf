# Clients v3 — элементы прототипа без согласованного контракта

Матрица только для действий, которым **нельзя** дать реализацию без решения владельца. Вёрстка, навигация, фильтры и карточки команды с данными fixtures — не блокируются этим документом.

| Элемент прототипа | Источник / route / API | Роли | R/W | Нужное решение владельца |
|-------------------|------------------------|------|-----|---------------------------|
| Быстрые действия в строке списка (иконки/меню) | `GET /api/clients/v3/list` + UI `#clients-table-body` | manager, regional, rop, director, admin | write (предпол.) | Перечень действий, права по роли, idempotency, audit; какие поля 1С/Б24 затрагиваются |
| Конструктор полей «ИНН / ТОП» в admin field map | `GET /api/clients/v3/field-catalog`, `/clients/field-map` | admin | write | Согласовать семантику полей, валидацию и сохранение (если не только read-only catalog) |
| Массовые операции по выделенным строкам | нет API | все с полным доступом | write | Нужен ли multiselect строк и batch endpoint |

Все остальные расхождения текущего спринта (отступы, колонки, баннер делегирования, карточки команды, multiselect, return) закрываются в PR без нового контракта.
