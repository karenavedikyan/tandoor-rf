# Закрытая разовая проверка обмена 1С

Назначение: сверить GUID сотрудников и назначений перед переносом команд.
Не импортирует клиентов и не создаёт связи, учётные записи или права.
Интерфейс, логотип, цвета и карточка клиента не изменяются.

## Запуск

1. Оператор БД применяет миграцию `005_onec_diagnostic_jobs.sql`.
2. Вставляет одну запись в `onec_diagnostic_jobs` с `expires_at` не позднее двух часов.
3. При следующем запуске сервера выполняется не более одной актуальной pending-записи.
4. Результат читает оператор непосредственно из БД. HTTP-доступа к отчёту нет.

Задание имеет фиксированный тип. URL, код, команды и путь из БД не принимаются.
Читается только `/LC/clients/all_clients.json` с настроенного `gw.toopatch.ru`.
FTP использует действующий согласованный режим plain; это не шифрованный канал.

## Защита и ограничения

- Без задания FTP не вызывается. Просроченные и уже выполненные задания не повторяются.
- Сбой после claim оставляет running-запись для ручного разбора, не запускает повтор.
- Advisory lock предотвращает параллельные чтения; подключение освобождает lock.
- Максимум файла 32 MiB (по фактически прочитанным байтам), чтения 60 секунд, отчёта 2 MB.
- В отчёте: время чтения, SHA256, состав полей, GUID клиентов/холдингов/менеджеров,
  ФИО менеджеров, дубли, счётчики. Нет адресов, телефонов, имён клиентов и финансовых значений.
- Нет полного исходного файла в логах, БД или HTTP. Ошибки возвращают фиксированный код.
- ФИО и наличие GUID не подтверждают назначение прав и идентичность автоматически.
- Время чтения не является датой выгрузки 1С; дата формирования пока неизвестна.
- После сверки оператор удаляет отчёт согласно принятому сроку хранения.
- Для отката приложения вернуть предыдущий SHA; таблица совместима со старой версией.
