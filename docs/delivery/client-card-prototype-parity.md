# Карточка клиента: визуальная структура прототипа v2

## Основание и границы

28.09.2026 владелец запросил привести карточку к полному соответствию прототипу.
Эталон: v2 от 25.09.2026, экраны overview и passport.
Изменяется карточка, а не вся оболочка и не интеграции R2–R8.

В области карточки применены Golos и токены v2. Exo 2 и глобальная оболочка
других страниц не изменены. Это локальное следование новому запросу владельца,
а не принятие нового брендбука для всего продукта.

## Соответствие

| Элемент прототипа | Реализация |
|---|---|
| Заголовок и контекст клиента | Текущая запись 1С; не объявляется холдингом автоматически |
| 9 вкладок в исходном порядке | Обзор, Данные, Работа, Витрина, Заказы, Финансы, Документы, Рекламации, План |
| Обзор: полоса показателей | Исходная структура; отсутствующие значения показаны как «— / не подключено» |
| Следующие действия и точки/контакты | Две колонки, подтверждённые контакты и отсутствие интеграций |
| Данные: три колонки | Холдинг и ответственность; Магазин и доставка; Расчёты и договор |
| Нижняя строка | Особенности работы; Качество данных |
| Контакты, источник, технические сведения | Дополнительные рабочие блоки для текущего объёма данных |
| Мобильный интерфейс | Одна колонка, прокручиваемая полоса вкладок, сетка показателей 2×2 |
| Тёмная тема | Палитра v2 в области карточки |

## Не подменять готовность

Обзор и Данные воспроизводят структуру эталона с честными отсутствующими значениями.
Содержимое будущих разделов пока представлено состоянием «не подключено»,
а не полными рабочими экранами из прототипа. Полное функциональное соответствие
продукта и всего R1.4 не заявляется. Предупреждение о блокировке скидок из демо
не переносится без реальных данных.

Неизвестные категория, юрлица, ТТ, договор, региональный менеджер, РОП, скидки,
планы, долг, рекламации и задачи не вычисляются и не заполняются демо-значениями.
API, requireAdmin, импорт, БД, FTP и правила разграничения доступа не меняются.

## Проверка

Unit, typecheck, build; браузерные проверки настоящих страниц с синтетическими
API-ответами: контакты, возврат, вкладки мышью/клавиатурой, тёмная тема,
1440/390 px, длинные значения. Это не тест production-сессии или серверных прав.
