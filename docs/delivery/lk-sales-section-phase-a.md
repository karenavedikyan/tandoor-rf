## Факты 1С (зафиксированы, не додумывать)

| Файл (под `/LC/`) | Назначение |
|-------------------|------------|
| `sale/sale.json` | агрегат продаж по юрлицу × месяц × категория |
| `sale/sale(items).json` | детализация по товарам (SKU) |
| `sale/returne.json` | агрегат возвратов |
| `sale/returne(items).json` | детализация возвратов по товарам |

- `client_info.guid` — канонический ключ юрлица (= `guid_client` в `all_clients.json`).
- `client_info.id` — только обратная совместимость, если `guid` отсутствует; конфликт `guid`/`id` → отказ импорта.
- В `(items)` добавлены `guid_item` (SKU) и `name_item`; **вложенность полей в JSON ещё не подтверждена** фактическим файлом.
- Месяц только из поля `month`.
- Пять категорий: ВХОДНЫЕ ДВЕРИ; МЕЖКОМНАТНЫЕ ДВЕРИ; МЕЖКОМНАТНЫЕ ДВЕРИ (ПОГОНАЖ); Фурнитура (ручки); Фурнитура (прочее).
- `income` уже с учётом скидок; не вычитать скидки повторно.
- Продажи и возвраты — **разные источники**; не суммировать aggregate + items; не смешивать sale/return в одной записи.
- Сверка item → aggregate по `guid_client` + `month` + category — после чтения actual JSON.
