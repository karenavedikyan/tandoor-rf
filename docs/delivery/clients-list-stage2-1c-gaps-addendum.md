# Список v3 (этап 2): дополнения к пробелам 1С

Базовый документ карточки: [clients-card-1c-missing-data.md](./clients-card-1c-missing-data.md). Здесь только **новое** для экрана списка/фильтров (lktandoor), без повтора этапа 1.

| Тема | Факт для списка |
|------|------------------|
| Город юрлица | Только структурированное поле v3 (`LEGAL_CITY_SQL`); если в выгрузке пусто — фильтр «Город» для клиентов честно недоступен (options `cities: []`). |
| Статус юрлица в колонке | Показываем только подтверждённый `status_label` из v3; произвольный `colStatus` без совпадений → 0 строк (не «все»). |
| Field-builder | `filters` JSON (AND, до 12 правил) — allowlist полей v3 list SQL: категория/тип/ответственные GUID, город, статус юрлица, closed/адрес/LPR/Club/приёмка ТТ, missingManager; **не** INN/договор/сквозная legal→retail корреляция в одном правиле. |
| Счётчики в зелёной полосе | `GET /api/clients/v3/scope-summary` — totals по ACL+территории без пользовательских фильтров; не подменяют `total` списка при активных фильтрах. |
