## 1. FTP — три уровня (не смешивать)

| Уровень | Значение | Где |
|---------|----------|-----|
| **Базовый каталог** | `ONEC_FTP_BASE_PATH` — **обязательный** env; **runtime-default нет** | `src/onec-ftp/config.ts` |
| **Относительный путь** | `CLIENTS_RELATIVE_PATH = "clients/all_clients.json"` | `src/onec-clients/constants.ts` |
| **Итоговый path** | `{basePath}/clients/all_clients.json` | `src/onec-clients/path.ts` |

Пример: `ONEC_FTP_BASE_PATH=/LC` → `/LC/clients/all_clients.json`.  
`.env.example` содержит **пример** `/LC`, не default приложения.

### Разрешённая область (политика v1.1, не env)

| Путь (при base `/LC`) | Назначение | ЛК |
|-----------------------|------------|-----|
| `/LC/clients/all_clients.json` | Snapshot клиентов | импорт CLI ✅ |
| `/LC/catalog/` (`groups`, `section`, `products` + 5 коммерческих `*/data.xml`) | Товарный блок XML | **CLI import** (R3.1 ✅); **read API** во вкладке «Витрина» (R3.2 draft) — только активная версия PostgreSQL, без FTP |
| Заказы / финансы | — | **не исследовались** в R0.2 |

## 6. Статус R0.2

| Компонент | Статус |
|-----------|--------|
| Контракт 8 полей + правила обмена | ✅ документирован + синтетика |
| JSON-типы коммерческих полей | 🟡 **наблюдались**; семантика ⏸ Q4–Q6 |
| Расширенный JSON клиентов | ⏸ Q8 |
| Наблюдаемая структура каталога (8 XML) | 🟡 зафиксирована; полный контракт ⏸ Q12–Q17 |
| **R0.2 закрыт полностью** | **нет** — открыты семантика и гарантии |

Условия **R1.1**: подтверждение бизнес-правил коммерческих полей **Q4–Q6** и приёмка применимой части контракта. **Q8** блокирует расширение клиентов в **R1.2**, а **Q12–Q17** относятся к каталогу **R3**; они не являются техническими условиями реализации R1.1.

R0.2 целиком остаётся **partial**. До полного закрытия этапа переход к R1.1 требует отдельного согласования владельцем ограниченного объёма и обновления плана/промпта. Этот PR не разрешает переход автоматически и не переставляет релизы.
