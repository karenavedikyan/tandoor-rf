**Область FTP (политика v1.1):** `/LC/catalog/` при `ONEC_FTP_BASE_PATH=/LC`  
**Импорт в ЛК (R3.1):** CLI `onec-catalog-import` + migration `020_onec_catalog.sql` (**draft PR**). UI каталога **не входит** в R3.1.

> Наблюдаемая структура ниже подтверждена повторной проверкой **01.10.2026** (read-only FTP, `/LC/catalog/`).  
> Это **не** XSD и **не** полный согласованный бизнес-контракт. Счётчики относятся к одному снимку и **не** являются константами кода.

## 3. Реализованное поведение R3.1 (код)

| Правило | Реализация |
|---------|------------|
| Транспорт | Read-only FTP (8 фиксированных путей) или `--local-dir` для тестов |
| Dry-run | По умолчанию; apply только `--apply --expected-manifest-sha256` |
| Manifest | Канонический порядок 8 файлов: `path + size + sha256`; `manifestSha256` = SHA канонической строки |
| Стабильность | Двойное чтение FTP (apply); локальный режим — без повторного скачивания после проверки |
| Лимиты XML | 64 MiB/файл, 128 MiB/набор; sax; DOCTYPE запрещён; depth/elements/time limits |
| Базовый каталог | groups, sections, storages, price types, products (+ properties/images/sections) |
| Коммерция | prices/stock/stock_expected → **staging**; битые ссылки → **quarantine** |
| `commercialReady` | **всегда false** в R3.1 (семантика не утверждена) |
| Исчезновение SKU | Не удаляет старые версии; **блокирует apply** при падении count / потере известных кодов |
| Повтор manifest | Идемпотентен (`SKIPPED_UNCHANGED`) |
| Активная версия | Атомарное переключение `onec_catalog_state.active_version_id` |
| Клиенты | Таблицы `onec_clients` / journal **не изменяются** |

Корень иерархии: пустой `Родитель` / `КодРодителя`, `"0"` или отсутствие атрибута → `null` (не подменять на произвольный корень).

## 4. Ограничения и live-приёмка

- Production apply **не выполняется** из Cursor; требуется backup, dry-run на live FTP, review manifest SHA.
- Совпадение 8 SHA доказывает неизменность **прочитанных байтов**, не единую бизнес-версию 1С.
- Модель↔SKU, валюта, НДС, смысл `Доступно`, приоритет источников — **открыты** (Q12–Q17).
- Синтетика в repo **не заменяет** live-приёмку полного снимка.
