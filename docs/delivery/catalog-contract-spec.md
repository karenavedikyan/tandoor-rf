## 3. Ожидаемые сущности R3.1 (v1.1 — не имена тегов)

| Сущность | Назначение | Связи (ожидание) |
|----------|------------|------------------|
| Товар / номенклатура | SKU для отгрузки и каталога | группа, бренд, характеристики |
| **Модель** (витрина) | Абстракция для доли/витрины | **отдельно** от SKU |
| **Вариант** | Конкретная исполнение модели | → модель |
| Группа / раздел | Иерархия каталога | parent group |
| Тип цены | Справочник + ссылки в ценах | **не подставлять** произвольно |
| Склад | Остатки | товар/вариант |
| Остаток | Число на дату snapshot | склад + номенклатура |
| Ожидаемое поступление | Отдельный файл `stock_expected` | бизнес-смысл **уточняется** |

**Правило v1.1:** модель витрины ≠ конкретный SKU; связь модель↔SKU **только** по явному ID из обмена.

## 4. Ожидаемое поведение импорта R3.1 (спецификация, не код)

| Правило | Описание |
|---------|----------|
| Транспорт | Read-only XML-адаптер, отдельный от clients JSON |
| Dry-run | Обязателен до apply |
| Snapshot | Полный снимок; последняя корректная версия при ошибке |
| Согласованность | Набор файлов проверяется на внутренние ссылки |
| Неизвестный элемент/атрибут | Warning; **не** сохранять без контракта |
| Битая ссылка (в т.ч. тип цены) | Ошибка или warning — **решение 1С** (TBD; пример: §2.2) |
| Активность товара | **Не выводить** из отсутствия в файле (v1.1) |
| Цена | Тип цены только из подтверждённого поля; без «угадывания» |
| Изображения | Только защищённый источник; относительный путь ≠ публичный URL |
